OWASP Benchmark Comparison

Security tools run against the same OWASP Benchmark test suites and scored by the same OWASP scorer, so their results can be compared side by side. Select a tool to open the full OWASP scorecard for it.

Not an official OWASP leaderboard

We do not own OWASP, the OWASP Benchmark or BenchmarkUtils, and this page is not affiliated with or endorsed by the OWASP Foundation. OWASP publishes no official leaderboard, so this page collects results in one place to help people compare tools on the same dataset and the same evaluation. Every score here is copied from a scorecard produced by OWASP's own BenchmarkUtils, run on OWASP's unmodified benchmark repositories.

How the numbers are made

  • Dataset. OWASP's own BenchmarkJava (2,740 test cases) and BenchmarkPython (1,230), pinned to one commit each and never edited. Each test case is either really vulnerable or a deliberate false alarm.
  • Evaluation. OWASP's BenchmarkUtils reads each tool's own report and writes the scorecard, through each benchmark's own createScorecards.sh. Nothing in this project maps findings or computes scores.
  • Score. True-positive rate minus false-positive rate (the Youden index), averaged over the vulnerability categories, so each category counts equally whatever its size. 0% is what random guessing scores; a negative score is worse than guessing.
  • Sources. OWASP reference rows come from the results OWASP ships inside each benchmark repository. Run here rows are tools this project ran on the same pinned benchmark.

Reproduce any row:

git clone --recurse-submodules https://github.com/Inverse-Vibe/OWASP-Benchmark-Comparator.git
cd OWASP-Benchmark-Comparator && pip install -e .
